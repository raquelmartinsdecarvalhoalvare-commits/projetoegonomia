Principais tags (códigos) e recursos usados

Estrutura de pastas

ergonomia-site/
├── index.html
├── paginas/        (demais páginas HTML)
├── css/style.css   (visual e paleta de cores)
├── js/script.js    (menu, paleta, checklist, perguntas, zoom)
├── img/            (imagens usadas no site)
└── docs/           (planejamento e links da legislação)

Principais tags HTML

Quadro 3 – Tags HTML mais usadas
TagPara que serve
<!DOCTYPE html>Indica que o documento é HTML5.
<html lang="pt-BR">Raiz da página e idioma.
<head>, <title>, <meta>, <link>Informações da página, título e ligação com o CSS.
<header>, <nav>, <main>, <section>, <footer>Organizam a estrutura da página.
<h1> a <h3>, <p>Títulos e parágrafos.
<ul>, <ol>, <li>Listas.
<a href="...">Links entre páginas e para sites externos.
<img src="..." alt="...">Imagens, com texto alternativo para acessibilidade.
<figure>, <figcaption>Figura com legenda (padrão ABNT).
<table>, <tr>, <th>, <td>Tabelas e quadros.
<button>, <input>, <label>Botões e campos interativos.
<script src="...">Liga o arquivo JavaScript.

Exemplos de código

HTML

<figure>
  <figcaption>Figura 1 – Título</figcaption>
  <img src="../img/postura-perfeita.png" alt="Descrição">
  <p>Fonte: URL</p>
</figure>

CSS (variáveis de cor)

:root {
  --primary: #344879;
  --bg: #F2F4F8;
}
body { background: var(--bg); }

JavaScript (abrir e fechar o menu)

botaoMenu.addEventListener('click', function () {
  menu.classList.toggle('aberto');
});

Materiais e recursos usados

  • HTML5, CSS3 e JavaScript puro, sem bibliotecas nem banco de dados.
  • Editor de código e navegador para testar.
  • Paleta de cores definida pela equipe, com duas opções (azul e rosa) no botão “Trocar paleta”.
  • Imagens de exemplo escolhidas pela equipe, com fonte indicada em cada figura.
  • Textos baseados na IEA (2020) e na legislação brasileira, conforme as referências.
  • Assistente de IA (Claude) usado para gerar a estrutura inicial do código; conteúdo e referências revisados pela equipe.
