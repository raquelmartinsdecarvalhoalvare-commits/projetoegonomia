# Ergonomia na Prática – projeto acadêmico

Site informativo sobre ergonomia e legislação brasileira (HTML, CSS e JavaScript básicos, sem banco de dados).

## Como abrir
Descompacte o .zip e dê dois cliques em `index.html`.

## Estrutura
```
ergonomia-site/
├── index.html
├── paginas/   conceitos, ambiente, legislacao, imagens, integrantes, referencias, recursos, conclusao
├── css/style.css
├── js/script.js
├── img/       imagens usadas no site
└── docs/      esboços/paletas da equipe e links oficiais da legislação
```

## O que a equipe precisa preencher
1. URL de cada imagem: procure `[colar aqui o URL da imagem]` nas páginas e em `paginas/referencias.html`.
2. Instituição, curso/turma e professor(a): `paginas/integrantes.html`.
3. Conferir a linha sobre uso de IA em `paginas/recursos.html` conforme as regras da escola.
4. Conferir os textos de lei no Diário Oficial (links em `paginas/legislacao.html`).

## Paleta
Azul (padrão): #0A1024, #1A2751, #344879, #7185A8, #B7C4D9, #F2F4F8.
Rosa (botão "Trocar paleta"): tons de #4B0F1E a #F7D6DC. Os valores ficam no começo de `css/style.css`.
